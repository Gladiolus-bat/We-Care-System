# WeCare – Skincare Product Sale System

A compact Python CLI POS for WeCare skincare inventory, purchases, and sales, built as a college project.

## Project Overview

- Language: Python
- Interface: CLI
- Modules: file I/O, datetime

## Features

- **Buy 3 Get 1 Free Promotion**: Apply discounts automatically on bulk purchases.
- **Sell Returns**: Process customer returns and update inventory accordingly.
- **Stock Updates**: Easily add or modify product stock levels.
- **View Inventory**: Display current stock and product details.
- **Receipt Logging**: Generate and log transaction receipts for record-keeping.

## How to Run

1. Clone the repository
2. Run main.py to start the program! (python main.py)
